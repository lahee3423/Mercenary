# 용병 (Mercenary)

프랜차이즈 커피 매장의 긴급 인력 공백을 해당 카페 브랜드 경력 근로자와 연결하는 iOS/Android 앱입니다.

## 실행

```bash
npm install
npm start
```

Expo Go 앱으로 QR 코드를 스캔하거나 `npm run ios`, `npm run android`를 실행합니다.

## 현재 구현

- 점주/근로자 역할 선택 온보딩
- 프랜차이즈 커피 브랜드 선택
- 근로자용 추천 긴급 공고 및 확정 근무
- 점주용 빠른 구인, 지원 현황, 긴급 구인 진입점
- EAS development/preview/production 빌드 구성

앱스토어 배포 전 실제 인증, 경력/매장 검증, 공고·매칭, 출퇴근, 정산 API와 개인정보 처리 체계를 연결해야 합니다.
